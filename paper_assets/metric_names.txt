DIAGNOSTIC METRIC RENAMES (paper-facing)
=========================================

Original code names → paper-facing names. The originals stay in code/CSVs;
new names should be used in the paper text + figure axes.

----------------------------------------------------------------------
1. QPD — Query Pairwise Distance (was: Query Pairwise Diversity)
----------------------------------------------------------------------
Compares: the k turn-1 queries issued by the k parallel threads.
Type    : distance (1 - Jaccard similarity over word tokens).
Scope   : turn 1 only.
Range   : 0 (identical queries) → 1 (no word overlap).
Aggregation: per question = mean over all C(k,2) thread-pairs.
             per run     = mean over questions.
Higher is better for the diversity-parallel method.

Rename rationale: "Diversity" was vague — distance is mathematically what
we compute. Same acronym, sharper meaning.


----------------------------------------------------------------------
2. ITC — Intra-Thread Coherence (was: Inter-Turn Coherence)
----------------------------------------------------------------------
Compares: within a single thread, the turn-1 query against every later turn's query.
Type    : similarity (Jaccard similarity, NOT distance).
Scope   : per thread, across all turns 2..T.
Range   : 0 (later queries unrelated to turn 1, thread is "wandering")
        → 1 (later queries rephrase turn 1, thread is "stuck").
Aggregation: per thread = mean over later turns.
             per question = mean over threads.
             per run = mean over questions.
A bit lower is healthier (thread keeps exploring, doesn't get stuck on the
same query). Diversity-parallel typically shows lower ITC than naive,
suggesting diversity propagates beyond turn 1.

Rename rationale: "Inter-turn" implied "between two turns of different
things"; really it's "within one thread, over its turns." "Intra-thread"
is unambiguous. Same acronym.


----------------------------------------------------------------------
3. ATD — Across-Thread Distance (was: ATC, Across-Thread Coherence)
----------------------------------------------------------------------
Compares: at each turn t in [1..T], the k queries issued by the k threads.
Type    : distance (Jaccard distance, despite the old "Coherence" name).
Scope   : every turn, not just turn 1.
Range   : 0 (all k threads issuing identical queries at every turn)
        → 1 (k threads always fully diverse across all turns).
Aggregation: per turn = mean over thread-pairs at that turn.
             per question = mean over turns.
             per run = mean over questions.
Higher is better for diversity-parallel — shows that turn-1 diversity
PERSISTS through the rollout (doesn't collapse to naive by turn 4).

Rename rationale: the old name "Coherence" suggested similarity, but the
quantity is a Jaccard *distance*. Same direction as QPD (higher = more
diverse). New acronym ATD reflects that it's a Distance.
